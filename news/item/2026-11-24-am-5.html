Anthropic launches Claude Ship, a set of AI agents that can review, fix and approve code changes

Anthropic recommends running Claude Approvals in observe-only mode at first, and teams choose which changes still need a person to sign off, TechCrunch reported. Developers can also start the process on their own pull requests with a new /ship command in Claude Code. The Verge reported that Code Review became generally available in October. Details are in Anthropic's announcement.

Why it matters: It moves AI coding tools from writing code toward approving it for release, a step that has usually been left to human reviewers.
